Braves BIM Field

Política de Privacidade

Última atualização: 13 de setembro de 2026

Esta política explica quais dados o aplicativo Braves BIM Field coleta, como eles são usados e com quem podem ser compartilhados. O app é feito para levantamento de campo em obras (medições, croqui, fotos e dados de ambientes), sincronizado entre um tablet e um celular do mesmo levantamento.

1. Quem é o responsável pelo aplicativo

O Braves BIM Field é desenvolvido e mantido pela Braves Engenharia. Dúvidas sobre esta política ou sobre seus dados podem ser enviadas para braves.engenharia@gmail.com.

2. Quais dados o app coleta

  • Dados do projeto/edificação: nome do imóvel, endereço, tipo de construção e número de níveis, informados por quem cria o levantamento.
  • Dados de ambientes: nomes, medidas, croqui (paredes, portas, janelas, escadas, coberturas), acabamentos e observações.
  • Localização (GPS): somente quando você toca em "Marcar local" em um ambiente — nesse momento o app pede a localização atual do aparelho e a grava junto com aquele ambiente. Se você nunca usar esse botão, nenhuma localização é coletada.
  • Fotos: ao anexar uma foto a um ambiente, ela é usada apenas para pré-visualização durante a sessão atual no aparelho — não é enviada nem armazenada em nossos servidores.
  • Identificador do aparelho: um código aleatório gerado e salvo no próprio aparelho (não é um dado pessoal, não identifica você), usado só para coordenar a sincronização entre o tablet e o celular do mesmo levantamento.

O app não pede cadastro, login, e-mail ou senha para ser usado.

3. Como os dados são usados

Os dados listados acima são usados exclusivamente para o funcionamento do levantamento: manter o croqui e as informações do projeto sincronizados entre os aparelhos usados na mesma obra, e permitir a exportação/importação desses dados (por exemplo, para o Revit). Não usamos os dados para publicidade, perfilamento de usuários ou qualquer finalidade fora do funcionamento do app.

4. Com quem os dados são compartilhados

  • Firebase (Google): quando a sincronização entre aparelhos está ativa, os dados do projeto (item 2) são armazenados no Firestore, serviço de banco de dados da Google, associados apenas ao código do projeto — não a uma conta ou identidade pessoal.
  • ViaCEP: ao digitar um CEP no cadastro do imóvel, esse CEP é enviado ao serviço público ViaCEP para preencher automaticamente o endereço.
  • Sentry: se o app travar ou apresentar um erro inesperado, informações técnicas sobre esse erro (mensagem, ponto do código, tipo de aparelho/navegador) são enviadas ao Sentry para nos ajudar a identificar e corrigir o problema. Isso não inclui os dados do seu levantamento, fotos ou localização.

Não vendemos nem compartilhamos seus dados com terceiros para fins comerciais ou de publicidade.

5. Onde os dados ficam guardados

Os dados de cada levantamento ficam salvos localmente no aparelho (mesmo sem internet) e, quando a sincronização estiver configurada, também na nuvem (Firebase), associados ao código do projeto. Você pode apagar um levantamento a qualquer momento pelo próprio app; para solicitar a remoção de dados sincronizados na nuvem, entre em contato pelo e-mail acima informando o código do projeto.

6. Permissões usadas pelo app

  • Câmera: usada apenas quando você toca no botão de anexar foto a um ambiente.
  • Localização: usada apenas quando você toca em "Marcar local".

Nenhuma dessas permissões é acessada em segundo plano ou sem uma ação explícita sua.

7. Crianças

O Braves BIM Field é uma ferramenta profissional de levantamento de obras e não é direcionado a crianças.

8. Alterações nesta política

Esta política pode ser atualizada caso o app passe a coletar ou usar dados de forma diferente. A data no topo desta página indica a versão mais recente.

9. Contato

Dúvidas, solicitações de exclusão de dados ou qualquer outra questão sobre privacidade: braves.engenharia@gmail.com.
